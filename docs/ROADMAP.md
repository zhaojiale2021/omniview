# Omniview 功能增加计划

按优先级排列；完成项可在合并 PR 时勾选。

## P0：稳定性与基础体验
- [ ] **Windows 原生 CI**：在 windows-latest runner 上直接构建 Windows 版本，与 WSL 交叉编译形成双保险
- [ ] **Release 自动发布 notes**：自动生成 changelog（从 PR/commit 提取）
- [ ] **崩溃日志**：Windows 端增加 panic 捕获写日志，方便用户反馈
- [ ] **播放状态持久化增强**：记住音量、播放速度、360 模式、窗口位置/大小

## P1：播放体验
- [ ] **硬件解码**：ffmpeg-next 增加 `dxva2/d3d11va` 等硬解，降低 4K/8K CPU 占用
- [ ] **字幕支持**：外挂/内嵌 SRT/ASS 字幕，可选字体、大小、颜色
- [ ] **音轨/视频轨切换**：多音轨、多字幕轨选择
- [ ] **播放列表**：打开文件夹/多选文件，自动连播，顺序/随机/循环
- [ ] **快进/快退预览**：长按左右方向键连续 seek
- [ ] **播放速度扩展**：0.25×–4× 更细粒度，自定义速度
- [ ] **音频增强**：均衡器、音量限制、夜间模式

## P2：360° 与交互
- [ ] **VR/陀螺仪支持**：手机/VR 设备方向控制视角
- [ ] **360° 视频投影模式**：equirect / cubemap / 小行星视角
- [ ] **鼠标/手柄控制优化**：惯性拖动、FOV 动画、双击复位
- [ ] **360° 视频空间音频**：随视角旋转的音频定位

## P3：界面与工程
- [ ] **皮肤/主题**：浅色/深色/自定义强调色
- [ ] **缩略图缓存持久化**：将 seek 缩略图保存到磁盘，减少重复解码
- [ ] **快捷键自定义**：可配置快捷键
- [ ] **国际化**：中英文界面切换
- [ ] **模块化测试**：增加 UI/渲染层单元测试、A/V 同步压力测试
- [ ] **代码覆盖率**：接入 codecov
